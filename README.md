# CLIHub

Windows-компаньон (system-tray + hotkey-попап) для запуска и обновления AI Agents CLI в папке проекта.

## Что это

CLIHub живёт в системном трее и открывается по глобальному хоткею (`Ctrl+Alt+Space`). Он ведёт реестр проектов, показывает установленные на хосте агенты (через встроенные плагины) и запускает их в терминале нужного runtime прямо в папке проекта — без ручного набора команд.

## Возможности

- Реестр проектов: папка, имя, лого.
- Динамический список агентов из встроенных плагинов (`plugins/agents/<folder>/agent.json`).
- Определение установленных на хосте агентов (probe) и инициализации проекта по маркерам.
- Запуск агента в терминале нужного runtime: `ps`, `cmd`, `wt`.
- Лого агентов и проектов (единая цепочка резолва, дефолт при отсутствии).
- Проверка обновлений CLIHub через Velopack — фоновая на старте; установка — по явному действию пользователя.

Состав UI и состояние реализации — в `docs/ui.md`.

## Состояние реализации

Уже доступно:

- system tray с пунктами «Settings» и «Exit» (+ «Install update», когда обновление готово);
- popup по глобальному hotkey;
- футер popup: версия приложения и системные действия (открыть папку данных, настройки, выход);
- добавление и удаление проектов;
- определение установленных и инициализированных агентов;
- запуск доступного агента в выбранном проекте;
- фоновая проверка обновлений CLIHub и установка готового обновления из tray;
- окно настроек: runtime по умолчанию, глобальный hotkey (press-to-capture), TTL/таймаут probe, проверка обновлений по требованию; вход — из tray-меню и футера попапа, один экземпляр.

Пока не реализовано:

- действия `resume`, `update` и `init` в popup;
- редактирование проекта и ручной override лого.

Целевое поведение описано в `docs/vision.md` и `docs/ui.md`, а актуальные
реализованные контракты — в `openspec/specs/`.

## Стек

- .NET 10 (LTS), WPF + WinForms, Windows-only.
- H.NotifyIcon (трей), Velopack (обновления), `RegisterHotKey` (P/Invoke).

## Требования

- Windows 10/11.
- .NET 10 SDK — для сборки; .NET Desktop Runtime 10 — для установленной сборки.

## Сборка и запуск

```powershell
dotnet build CLIHub.sln
dotnet test CLIHub.sln
dotnet run --project src/CLIHub.App
```

Окна при старте нет: приложение живёт в трее, попап открывается по `Ctrl+Alt+Space`. `dotnet run` не завершается сам — запускай фоном.

Обновления проверяются только у Velopack-установки; dev-запуск (`dotnet run`) проверку молча пропускает.
При доступном обновлении приложение показывает уведомление в tray, но не устанавливает
его автоматически.

## Структура

- `src/CLIHub.Core` — логика и контракты (net10.0, без WPF), покрывается тестами.
- `src/CLIHub.App` — WPF-оболочка, трей, хоткей, платформенный интероп; composition root — `App.xaml.cs`.
- `tests/CLIHub.Core.Tests` — xUnit.
- `plugins/agents/<folder>/` — встроенные плагины-агенты (манифест `agent.json` + ассеты).
- `openspec/` — спецификации и воркфлоу изменений.

## Конфигурация

`%AppData%\CLIHub\` (не в репозитории), хранение по файлам-владельцам:
`settings.json` (`runtime`, `hotkey`, `probe`, `update`), `projects.json` (`projects[]`),
`agents.json` (машинный кэш). Создаются автоматически.
