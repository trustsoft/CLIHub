# Refactoring Deviations

No deviations have been approved.

When a task cannot follow `design.md`, add an entry before changing the implementation:

```markdown
## DEV-XXX: <short title>

- **Task:** <task identifier>
- **Deviation:** <what differs from the design>
- **Reason:** <why the design cannot be followed>
- **Alternatives considered:** <other options>
- **Impact:** <behavior, API, dependency, and migration impact>
- **Temporary:** Yes/No
- **Decision:** <approved/rejected and by whom or in which review>
```
